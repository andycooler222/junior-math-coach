# 解答题表达规范自查表（对照实证阅卷规则）

> 实证依据：解析版逐项分值标注＋多方印证的阅卷规则——答案对≠满分，步骤分占大半。打印贴在书桌前，每次解答题做完逐条勾。

## 通用五查（每次必查）

- [ ] 写了"解："开头
- [ ] 分步书写，关键步骤括注依据（定理/公式名）
- [ ] 设未知数/设坐标有文字说明（"设点 P 坐标为 (m, …)"）
- [ ] 结果化简到最简，分式方程/无理方程已检验
- [ ] 应用题有定义域、单位、**答句**

## 按题型自查

### 计算/解方程（19-20 题）
- [ ] 分式方程：两边同乘最简公分母后**检验**写明
- [ ] 无理方程：平方后验根
- [ ] 不等式组：解集在数轴上表示（实心/空心区分）
- [ ] 实数混合运算：每项先化简再合并

### 几何证明（23 题）
- [ ] 每步"∵…∴…"，条件完整（判定条件一个不缺）
- [ ] 辅助线第一句描述（"过点 C 作 CH⊥AB 于 H"）
- [ ] 相似书写顺序＝对应顶点顺序
- [ ] 结论完整，不提前引用未证结论

### 函数与压轴（21、24、25 题）
- [ ] 求解析式：先写"设"（顶点式/交点式/一般式选哪种、为什么）
- [ ] 含参：先写二次项系数≠0；求出参数**代回检验**（Δ、a≠0）
- [ ] 图像性质表述带区间（"当 x>…时"）
- [ ] 分类讨论：分类依据先写一句（"按 ___ 分两种情况"），每种独立解，答案用"或"连接
- [ ] 存在性问题：设参数坐标→表示线段长→列方程→**检验取舍**（定义域、合题意）一个不落
- [ ] 应用题最后写"答：＿＿＿"（实证单独占 1 分）

## 扣分对照（实证规则速查）

| 情形 | 代价 |
|---|---|
| 答案对、关键步骤缺 | 扣 2-4 分 |
| 证明缺一个判定条件 | 扣 1-2 分 |
| 定义域/答句/单位缺一处 | 扣 1-2 分 |
| 分式方程不检验 | 固定扣分 |
| 分类漏一种 | 该小问过半分 |
| 压轴只写答案无过程 | 仅得 1-2 分 |
| 空白 | 0 分（写已知+结论+第一步公式即有步骤分） |
