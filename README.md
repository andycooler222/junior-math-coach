# junior-math-coach（初中数学学习教练）

Agent Skill：上海初中数学（沪教版五四制·六至九年级）诊断与训练。

## 这是什么

一个面向家长与孩子的数学学习教练技能，遵循"诊断 → 定位 → 训练 → 复测"闭环：

- **双身份**：对孩子只提问引导、不代做；对家长输出诊断结论与追问脚本
- **按能力点诊断**，不按题号；数学特有的**前置缺口回溯**（九年级失分先查七年级地基）
- **实证校准**：基于 2026-2027 学年六份上海初中数学实测卷（四份带答案/解析）与 2025 年上海一模/二模结构

## 安装

仓库根目录即技能目录。放入 WorkBuddy 技能目录：

```bash
cd ~/.workbuddy/skills
git clone https://github.com/andycooler222/junior-math-coach.git junior-math-coach
```

重启 WorkBuddy 后，说"帮我看看这张数学卷子"或"这道压轴题卡住了"即可触发。

## 四条铁律

1. 先要思路，再给帮助（不凭卷面猜孩子想法）
2. 一次只攻一个能力点
3. 诊断必须回溯前置（链式知识结构）
4. 结论要有依据（错在哪一步、哪类错误）

## 数据准确性声明

- 中考结构（选择 24＋填空 48＋解答 78）取自 2025 年上海一模/二模实证，历年以考试院说明为准
- 六份卷证来自 2026-2027 学年名校/联考月考卷，只取题型结构与给分规则，不复录原题；样本有限，不代表全市
- 沪教版五四制年级图谱按主题组织，以在校实际进度为准
