# 函数：方法卡与易错点（上海卷压轴主战场）

> 六份卷证中，函数相关内容占填空压轴与 24 题压轴的绝对主力（9-10 月范围：二次函数＋相似）。

## 一、函数通识

- 定义域意识：所有函数题第一问先问"定义域是什么"；应用题定义域由实际意义决定（利润>0、长度>0、时间≥0）
- 增减性表述："当 x>… 时，y 随 x 增大而增大"——必须带区间，不许说"y 越来越大"
- 易错：把"图像"当"图像的一部分"；忽略实际问题中的整数解（灯笼数、件数）

## 二、一次函数（七年级）

- y=kx+b：k 定方向、b 定截距；|k| 越大越陡
- 待定系数法：两点代入解二元一次方程组
- 与不等式结合：kx+b>0 的解集＝图像在 x 轴上方部分的横坐标范围（图像法优先）

## 三、反比例函数（八年级）

- y=k/x（k≠0）：k>0 双曲线在一三象限（每支内 y 随 x 增大而减小）
- 核心构图：点在曲线上 → S=|k|/2 的矩形/三角形面积意义
- 与一次函数交点：联立方程组，交点个数即方程组解的个数

## 四、二次函数（九上核心，重点板块）

### 1. 三种表达式与选用

| 形式 | 适用已知 | 关键 |
|---|---|---|
| 一般式 y=ax²+bx+c | 三点 | 联立三元 |
| 顶点式 y=a(x−m)²+k | 顶点/对称轴/最值 | 先定 m、k，再代一点求 a |
| 交点式 y=a(x−x₁)(x−x₂) | 与 x 轴两交点 | 代第三点求 a |

### 2. 图像性质五件套（填空高频）

- 开口：a>0 向上（有最小值）；a<0 向下（有最大值）
- 对称轴 x=−b/(2a)；顶点 (−b/2a, (4ac−b²)/4a)——**配方求顶点更稳**
- a、b、c 符号判断口诀：开口看 a、交点看 c、对称轴定 b（左同右异）、Δ 定交点个数
- 与 x 轴交点：令 y=0 → Δ 判个数；交点距离 |x₁−x₂|=√(Δ)/|a|（弦长公式，压轴常客）
- 平移口诀：左加右减（x）、上加下减（y）；**平移不动 a**

### 3. 含参问题三件套（实证多卷）

- "是二次函数"⇒ a≠0
- "与 x 轴有/无交点"⇒ Δ 关系式
- "与 x 轴只有一个交点"⇒ Δ=0；"顶点在 x 轴上"⇒ Δ=0 且对称轴≠0 无需——直接 Δ=0
- 求出参数**必代回检验**（a≠0、Δ 条件）

### 4. 函数与几何综合（24 题压轴框架）

标准流程：求解析式 → 求特征点（与轴交点、顶点）→ 设动点坐标（用参数 m 表示）→ 表示相关线段长（垂直则用纵坐标差；水平则用横坐标差）→ 按几何条件（等腰/相似/面积）列方程 → 分类讨论 → 检验取舍（定义域、合题意）

- 等腰：三种分类（AB=AC / AB=BC / AC=BC），分别列方程
- 直角：勾股逆定理算三边平方，或造垂线
- 相似：先定对应关系（通常两解），用"对应边成比例"列式；坐标表示线段长要取绝对值
- 面积：铅垂高×水平宽/2（割补法），比直接底×高稳

## 五、新定义题（填空 17-18 常客，实证"牵手二次函数"）

1. 别慌：新定义题难在**读题**不在知识
2. 三步：用自己话复述定义 → 把定义翻译成方程/条件 → 套用已知函数知识
3. 实证技巧："与 x 轴有相同交点"⇒ 共轭根/同对称轴；这类条件优先用对称性而非硬算

## 六、诊断问题脚本（孩子模式）

- "这题抛物线的对称轴是多少？顶点呢？"（性质五件套抽测）
- "你设的点坐标是什么？用它表示的那条线段长是多少？"（压轴三步抽测：设→表示→列）
- "这里为什么要分两种情况？"（分类意识）
- "这个解要舍吗？为什么？"（检验意识）

（家长模式：四问对应四个能力点——性质熟练度、参数化能力、分类习惯、检验习惯。哪问答不上，读对应小节。）
