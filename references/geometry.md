# 图形与几何：方法卡与易错点

## 一、全等三角形（八年级地基）

- 判定五法：SAS、ASA、AAS、SSS、HL（限直角三角形）
- 证明表达三件套：条件写全（"∵…∴…"并括注依据）→ 结论精确到对应关系 → 图上标记
- 常见辅助线模型：中线倍长、角平分线作垂线、截长补短
- 易错：SSA 不是判定；对应顶点顺序写错导致"对应边"错位
- 前置角色：全等表述不过关 → 相似证明（九上）必丢分，先回炉表达规范

## 二、特殊四边形

- 判定链要"双向"记：平行四边形 ⇐ 一组对边平行且相等 / 对角线互相平分；矩形 ⇐ 平行四边形＋一个直角 / 对角线相等；菱形 ⇐ 平行四边形＋邻边相等 / 对角线互相垂直；正方形＝矩形＋菱形
- 中位线：三角形中位线∥第三边且等于一半；梯形中位线
- 实证出现的高频构图（普陀联考 22 题）：矩形内交叉连线交点，证平行四边形→菱形。套路：先用全等证对边相等得平行四边形，再用"对角线互相垂直"收口
- 易错：判定条件凑不齐就下结论（缺"平行四边形"这一层）；对角线条件张冠李戴（矩形对角线相等 vs 菱形对角线垂直）

## 三、相似三角形（九上核心，压轴主力）

- 判定：两角；两边夹角；三边；平行线截比例
- **模型识别表**（见到什么想什么）：

| 图形信号 | 模型 | 动作 |
|---|---|---|
| 一条平行线截两边 | A 字型 / 8 字型 | 直接写比例式 |
| 两个等角共顶点 | 一线三等角（K 型） | 造两次全等/相似 |
| 公共边/公共角 | 共角共边型 | 找第二对等角 |
| 中点 | 中位线/倍长中线 | 造平行、转移线段 |
| 直角＋斜边上中线 | 斜边中线=一半 | 转化为等腰 |

- 性质链：相似比 k → 周长比 k → **面积比 k²** → 对应高/中线/角平分线比 k
- 易错（实证高频）：面积比当相似比用；对应边顺序写反；"相似比"与"位似比"混（位似是特殊的相似，注意方向与坐标变化）

## 四、锐角三角比与解直角三角形

- 定义：sin=对/斜、cos=邻/斜、tan=对/邻、cot=邻/对；**只对直角三角形中的锐角定义**
- 特殊值表必须滚瓜烂熟（30/45/60）
- 解题框架：找（或造）直角三角形 → 已知两元素（至少一边）→ 选对三角比
- 应用题（坡度/仰俯角）：先画图标注，坡度 i＝铅直:水平＝tanα
- 易错：非直角三角形直接用三角比；把"边"当"比对边"；结果保留有效数字的要求漏做

## 五、圆（九下）与图形运动

- 垂径定理及其推论（弦心距、半弦、半径、弦心距构成直角三角形——勾股计算主力）
- 圆周角定理：同弧圆周角=圆心角一半；直径所对圆周角=90°（见直径造直角！）
- 切线：判定（过半径外端且垂直）与性质；切线长
- 图形运动三型：平移（扫过面积=底×平移距离＋首尾图形）、翻折（对称轴两侧全等）、旋转（对应点到旋转心等距、夹角=旋转角）
- 易错：翻折后"重合部分"没找全；旋转角找错对应边；点在弧上运动时轨迹意识缺失

## 六、证明表达规范（实证扣分大户，B 级）

1. 每步"∵…（条件），∴…（结论）"，关键步骤括注定理名
2. 辅助线第一句必须描述："过点 C 作 CH⊥AB 于 H"——不写扣分
3. 判定定理写全称："两组对边分别平行的四边形是平行四边形"，别只写"平行四边形判定"
4. 相似书写顺序＝对应顶点顺序，如 △ABC∽△DEF 中 A↔D、B↔E、C↔F
5. 结论别提前："由 ①② 得"要等 ①② 真的都证完

## 七、诊断问题脚本（孩子模式）

- "这个图里你看到哪个熟悉的模型？"（先逼模型识别，再谈计算）
- "要证菱形，还差什么条件？这个条件能从哪里来？"
- "这条辅助线是谁告诉你的？以后看到什么信号要想到它？"
- "这题的相似比是多少？面积比呢？"（专打 k 与 k² 混淆）
