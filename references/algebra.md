# 数与代数：方法卡与易错点

> 按"概念边界 → 方法框架 → 易错点"组织。诊断时先判断属于哪一层，再选对策。

## 一、实数与二次根式

- 概念边界：√a²＝|a|（不是 a）；负数没有平方根；最简二次根式两个条件
- 运算框架：先化简每一项（化为最简）→ 合并同类二次根式
- 易错：分母有理化的符号错误；√2×√3 与 √6 的混淆；去绝对值忘讨论
- 19 题高频动作：零次幂、负整数指数幂、特殊角三角函数值、绝对值——四件套各算各的，最后合并

## 二、整式与因式分解

- 概念边界：单项式的次数（所有字母指数和）；多项式"几项几次"
- 方法优先序：提公因式 → 公式法（平方差/完全平方）→ 十字相乘 → 分组
- 易错：提公因式漏负号；完全平方 a²±2ab+b² 中间项系数；十字相乘常数项符号
- 前置角色：因式分解不通 → 解一元二次方程必断

## 三、分式

- 概念边界：分母≠0；分式值为 0 的条件（分子=0 且分母≠0）
- 运算框架：先因式分解再约分；通分用最简公分母
- 易错：约分时"部分约掉"（只约了部分公因式）；符号变换 (a−b)² 与 (b−a)² 相等但 (b−a)³＝−(a−b)³

## 四、方程与方程组

- 一元一次方程：去分母勿漏乘不含分母的项（经典符号错）
- 二元一次方程组：代入法/加减法选择；解要代回**两个**方程验
- 分式方程：**必须检验**（增根）；设元后两边同乘最简公分母
- 无理方程：平方后必须验根；两边平方可能产生增根
- 二元二次方程组：消元降次思想；"一个二元二次＋一个二元一次"用代入法

## 五、一元二次方程（九上核心）

- 三种解法优先序：开平方法（缺一次项）→ 因式分解/十字相乘 → 求根公式
- 判别式 Δ：Δ>0 两不等实根；Δ=0 两相等；Δ<0 无实根
- **根与系数（韦达）**：x₁+x₂＝−b/a，x₁·x₂＝c/a。使用前提：a≠0 且 Δ≥0
- 易错（高频坑，实证多卷出现）：
  - 含参方程"是二次方程"⇒ 二次项系数≠0，先写这条再谈判别式
  - "有实数根"包括相等两根（Δ≥0 不是 Δ>0）
  - 求出参数后**代回检验 Δ**（解出的参数可能让 Δ<0 或 a=0，必须舍）

## 六、不等式与不等式组

- 概念边界：两边乘/除负数必须变号（最大失分源之一）
- 解集口诀：大大取大、小小取小、大小小大中间找、大大小小无处找
- 数轴表示：实心点/空心圈；应用题最后解集要符合实际（人数取整等）
- 易错：不等式组求"参数范围"要**逆向**讨论——已知解集反推参数时，端点是否取等要分类验证

## 七、诊断时的问题脚本（孩子模式）

- "这道题你第一步做了什么？为什么？"
- "解出来的答案你代回去验过吗？"
- "这个含参数的题，参数等于 0 的时候是什么？"
- "这两解都合理吗？把第二个代回去试试。"

（家长模式：把上面四问转成照念脚本，孩子答不上来再讲对应知识卡。）
