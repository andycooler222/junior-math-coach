# 统计概率与解题策略

## 一、统计初步（22 题固定考点）

- 四个量：平均数（受极端值影响）、中位数（排序后中间）、众数（出现最多）、方差（波动大小，越小越稳）
- 频率=频数/总数；扇形图圆心角=频率×360°；加权平均数要带权算
- 用样本估计总体：样本频率 × 总体数量
- 表达规范：结论要"答"；开放性建议题"能提出合理的优化建议"即有分（实证：建议单独计 2 分）——**不写建议=白丢分**
- 易错：中位数忘记先排序；方差算式中忘了除 n；图表中"不完整部分"要先用补全条件算出总数

## 二、概率

- 等可能事件概率 P=满足条件数/所有可能数
- 列举法：列表法（两步实验）与树状图（多步）；**结果要不重不漏**
- "放回"与"不放回"：不放回时第二次样本空间变小，常设坑
- 易错：只列"成功的"不列"全部的"；把"有序"和"无序"混（（A,B）与（B,A）是否算两种，看清题）

## 三、分类讨论完整度自查（数学最大失分源）

按信号词查分类：

| 题目信号 | 必查分类 |
|---|---|
| 等腰三角形（未指明） | 底与腰的两种；顶角与底角两种 |
| 直角三角形（未指明直角顶点） | 直角在哪个顶点 |
| 相似（未给对应关系） | 两种对应 |
| 抛物线含参 | a≠0；Δ 的情形；参数解代回 |
| 点的位置（"在直线上/平面内"） | 两侧各一；线段延长线两侧 |
| 图形运动/旋转 | 旋转方向两向；重叠区域变化分界点 |
| 绝对值/平方 | 正负两支 |

**实证规则**：压轴题漏一种情况≈扣该小问一半分；答案两个解之间用"或"连接，只写一个=半对。

## 四、压轴题拆题策略（针对"不敢动笔"）

六份卷证＋教研共识：24/25 题按小问分层给分，**前两问是中档题水平**。

1. **第一问（送分）**：求解析式/参数——用待定系数法，任何会解方程组的孩子都能拿。禁止因"压轴题"三个字跳过
2. **第二问（中档）**：单一工具应用（勾股逆定理/相似/韦达）。卡住时回到"要求什么→差什么→差的条件从哪个已知来"三问
3. **第三问（拉分）**：存在性/分类/最值。**先写"设"**：设出点坐标（一个参数），把要求的量用参数表示出来——这一步就有步骤分。能列几个方程列几个，做不下去也把分类框架写全
4. **时间策略**：优先保证 1-23 题全对再回来攻压轴第三问；填空 18 题超过 6 分钟先放

## 五、考试时间分配建议（100 分钟 / 150 分参考）

- 选择+填空（72 分）：30-35 分钟，18 题可暂跳
- 19-22（40 分）：20 分钟，稳、全、规范
- 23-24（24-27 分）：25 分钟
- 25 题：15 分钟（前两问拿稳，第三问尽力）
- 检查 5-10 分钟：优先查分式方程检验、定义域、答句、单位、分类完整性

## 六、错题归因五类（流程 D 用）

1. **概念不清**：说不出定义/判定的准确内容 → 回知识卡概念边界
2. **运算失误**：思路对、算错 → 限时重算＋符号专项
3. **方法缺失**：不知道用哪个工具 → 补模型识别表
4. **表达失范**：对了但被扣分 → 对照 `assets/answer-template.md` 自查表
5. **前置断链**：本题知识懂、前置不会 → 转流程 A 回溯（对照 `exam-map.md` 图谱）

## 七、诊断问题脚本（孩子模式）

- "这题的'所有可能情况'你列全了吗？漏了哪种？"
- "你为什么把它分成了这两种情况？分界点在哪？"
- "这题你卡在哪一步？卡住之前最后确定的一步是什么？"
